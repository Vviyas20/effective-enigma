# Outreach CRM design styles

Four UI/UX directions for Ospra's outreach CRM, each rendering the same sample
page (accounts in outreach, with fictional battery-maker prospects) so they can
be compared directly. Every style is a standalone `index.html` in its own
folder: open it in a browser, no build step. All four use the Ospra palette
(brand blue `#1447e6`, taupe neutrals) and type (Instrument Serif, Inter at
500+, DM Mono for tabular data only) from `design-system/tokens/`.

| Folder | Built for | The one bold idea |
| --- | --- | --- |
| `1-focus-queue/` | Reps working a daily cadence | A day's run tape that charges as each touch is sent; one prospect and one draft at a time, keyboard first (J/K, E to send, S to snooze, Cmd/Ctrl+Enter) |
| `2-pipeline-board/` | Managers and pipeline reviews | Stage lanes where every card's sequence progress is a battery cell glyph; drag between lanes, or focus a card and press `[` / `]` |
| `3-line-monitor/` | Power users with hundreds of accounts | A dark station readout: each row's sequence is a line of five stations; saved views, sortable columns, inline stage edits, bulk actions, Cmd/Ctrl+K command bar |
| `4-account-passport/` | Account-based selling to large plants | Each account as a digital identity record (static facts vs live engagement), a stakeholder map that shows the seats still empty, and a next best touch with reasoning |

All sample companies and people are fictional.
